# Day 25 – Basic Data Validation in Excel

## Project Overview
This project focuses on implementing basic data validation techniques in Microsoft Excel using the Kaggle HRDataset_v14 employee dataset.

The objective is to improve data accuracy, maintain consistency, and prevent invalid data entries.

## Dataset
- Source: Kaggle – HRDataset_v14
- Records: 311 employee records
- Format: CSV (converted into Excel)

## Operations Performed
1. Created an employee data entry sheet.
2. Added dropdown lists for:
   - Department
   - Gender
   - Employment Status
   - Recruitment Source
   - Performance Score
   - Marital Status
3. Applied Employee ID validation.
4. Restricted Age values between 18 and 70.
5. Applied Joining Date validation.
6. Added Salary range validation.
7. Validated Engagement Survey and Employee Satisfaction scores.
8. Applied Absences validation.
9. Highlighted duplicate Employee IDs.

## Tools Used
- Microsoft Excel
- Kaggle Dataset

## Deliverables
- Original Kaggle employee dataset
- Validated Excel data entry template
- Sample employee records
- Dropdown lists and validation rules
- Validation guide
